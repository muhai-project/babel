# OFEF Parser

This package allows you to export a FCG Construction Set (typically the \*fcg-constructions\* object) to the OFEF format (a specific type of JSON that allows importing grammars into PyFCG)

## Usage

After quickloading the package, use the main function in the following way :

```bash
(ofef-parser::fcg->ofef *fcg-constructions*)
```
